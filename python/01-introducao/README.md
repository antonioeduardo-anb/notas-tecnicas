# Python

Python é uma linguagem de programação de alto nível, interpretada, de propósito geral e multiparadigma. Ela oferece suporte aos paradigmas imperativo, orientado a objetos e funcional.

A linguagem utiliza tipagem dinâmica e forte, possui uma sintaxe simples e legível e enfatiza a clareza e a produtividade no desenvolvimento de software.

Python foi criado por Guido van Rossum e lançado oficialmente em 1991. Atualmente, seu desenvolvimento é conduzido de forma aberta e colaborativa pela Python Software Foundation (PSF), uma organização sem fins lucrativos responsável pela manutenção, evolução e divulgação da linguagem.

## Características

* Linguagem de alto nível.
* Interpretada.
* Multiparadigma.
* De propósito geral.
* Código aberto.
* Portável.
* Tipagem dinâmica e forte.
* Grande ecossistema de bibliotecas.
* Comunidade ampla e ativa.
